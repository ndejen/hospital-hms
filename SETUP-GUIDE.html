Complete Installation Guide for Windows
✅ Project Ready - Need PHP/Composer Setup

🚀 Quick Start (Recommended)

Current Issue: You're getting "composer not recognized" and "php not recognized" errors because PHP and Composer aren't installed yet.
1 Install XAMPP (includes PHP + MySQL + Apache)

Download from: https://www.apachefriends.org/

2 Move Project to XAMPP

Copy folder to: C:\xampp\htdocs\hospital-hms

3 Install Composer

Download from: https://getcomposer.org/download/

During installation: Use PHP path: C:\xampp\php\php.exe

📋 Step-by-Step Commands

After installing XAMPP and Composer, open Command Prompt as Administrator:

cd C:\xampp\htdocs\hospital-hms
copy .env.example .env
composer install
php artisan key:generate
php artisan migrate --seed
php artisan storage:link

🔗 Access the Application

After running all commands successfully, open your browser to:
http://localhost/hospital-hms/public
Note: If using XAMPP, make sure Apache and MySQL services are running (green in XAMPP Control Panel).
