OPTION 1: EASIEST METHOD (Using XAMPP)
=========================================================================

1. INSTALL XAMPP:
   - Download from: https://www.apachefriends.org/
   - Install to C:\xampp

2. COPY PROJECT TO XAMPP:
   - Copy the ENTIRE "hospital-hms" folder to:
     C:\xampp\htdocs\hospital-hms

3. START XAMPP:
   - Open XAMPP Control Panel
   - Start "Apache" and "MySQL"

4. CREATE DATABASE:
   - Open browser, go to: http://localhost/phpmyadmin
   - Click "New" on left sidebar
   - Database name: hospital_hms
   - Click "Create"

5. CONFIGURE PROJECT:
   - Navigate to: C:\xampp\htdocs\hospital-hms
   - Copy .env.example to .env
   - Edit .env file with Notepad:
        DB_DATABASE=hospital_hms
        DB_USERNAME=root
        DB_PASSWORD=  (leave empty)
        APP_URL=http://localhost/hospital-hms/public

6. INSTALL COMPOSER:
   - Download from: https://getcomposer.org/Composer-Setup.exe
   - Install Composer globally

7. RUN SETUP COMMANDS (Open CMD as Administrator):
   cd C:\xampp\htdocs\hospital-hms
   composer install
   php artisan key:generate
   php artisan migrate --seed
   php artisan storage:link

8. ACCESS APPLICATION:
   - URL: http://localhost/hospital-hms/public

=========================================================================
OPTION 2: USING LARAVEL BUILT-IN SERVER
=========================================================================

1. INSTALL PHP (if not using XAMPP):
   - Download PHP 8.2+: https://windows.php.net/download/
   - Extract to C:\php
   - Add C:\php to PATH environment variable

2. INSTALL COMPOSER:
   - Download Composer-Setup.exe from getcomposer.org

3. RUN FROM CURRENT LOCATION:
   - Open PowerShell in current folder
   - Run commands:
        composer install
        php artisan key:generate
        php artisan migrate --seed
        php artisan storage:link
        php artisan serve

4. ACCESS:
   - URL: http://localhost:8000

=========================================================================
TROUBLESHOOTING
=========================================================================

PROBLEM: "composer not recognized"
SOLUTION: Install Composer globally or use Composer PHAR:
   php composer.phar install

PROBLEM: "php not recognized"
SOLUTION: 
   - Use XAMPP (already has PHP)
   - OR install PHP and add to PATH

PROBLEM: Database connection error
SOLUTION:
   - Ensure MySQL is running in XAMPP
   - Check .env file has correct credentials
   - Database must exist: hospital_hms

PROBLEM: Permission errors
SOLUTION (run in CMD as Admin):
   icacls storage /grant "Users:(OI)(CI)F"
   icacls bootstrap\cache /grant "Users:(OI)(CI)F"
